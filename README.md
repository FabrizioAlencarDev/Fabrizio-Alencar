# Portfólio — Fabrizio Alencar

Portfólio profissional de Fabrizio Alencar, desenvolvedor Full Stack.

## Sobre o projeto

Site estático responsivo criado com HTML, CSS e JavaScript puro. O projeto apresenta experiência profissional, serviços, projetos públicos e canais oficiais de contato.

## Recursos

- HTML semântico e navegação por teclado
- Layout responsivo para celulares, tablets e desktops
- Metadados de SEO e compartilhamento social
- Imagens com dimensões definidas e carregamento tardio
- Menu acessível com `aria-expanded` e suporte à tecla Escape
- Destaque automático da seção ativa
- Suporte a `prefers-reduced-motion`
- Ano do rodapé atualizado automaticamente

## Tecnologias

- HTML5
- CSS3
- JavaScript
- Boxicons
- GitHub Pages

## Executar localmente

Abra o arquivo `index.html` no navegador ou utilize uma extensão de servidor local, como Live Server.
